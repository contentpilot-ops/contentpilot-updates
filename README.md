# ContentPilot · 多平台内容自动发布系统

> 一个作品，多平台同步发布。图文、视频全支持，文案按平台调性自动适配。

## ✨ 核心功能

| 功能 | 说明 |
|---|---|
| 🚀 四平台一键发布 | 小红书 / 抖音 / 快手 / B站，图文 + 视频全支持 |
| ✍️ 差异化文案 | 每个平台独立标题/正文/话题，按平台调性自动适配，不用一套文案走天下 |
| 🛡️ 敏感词自检 | 发布前自动拦截违规词/极限词/引流词，多级规则 |
| 🔁 发布防重复 | 历史标题自动比对，杜绝同题材重复发 |
| ⏱️ 防封号设计 | 发布频率控制 + 反自动化检测，账号更安全 |
| 📅 定时发布 | 到点自动发布，无需守着电脑 |
| 🤖 Agent 模式 | 内置命令行（CLI）+ HTTP API，支持豆包电脑版 / Codex 等智能体直接调用 |
| 🔄 内容热更新 | 文案 / 敏感词 / 频率参数云端更新，客户端自动同步，无需重装 |
| 🔐 本地数据 | 配置 / 历史 / 登录态全在本地 data 目录，不采集任何用户数据 |

## 🖥️ 产品形态

原生 Windows 桌面客户端（自带界面，无需浏览器插件），安装后桌面 / 开始菜单一键启动。

## 📦 系统要求

- Windows 10 / 11（64 位）
- 无需安装任何额外组件（自动调用系统 Edge 浏览器）

## 🔑 授权方式

- 免费版：每日 3 篇
- 专业版：每日 5 篇 + 定时发布 + 数据回传
- 一码一机，机器码绑定

## 📡 更新机制

本仓库为官方更新源：

- `version.json`：更新清单（客户端启动时自动比对）
- `content_config.json`：内容配置（文案 / 敏感词 / 频率参数，热更新）
- 客户端发现新版配置自动应用，全程无感
